Document Object Model (DOM)

La interfaz que conecta tus documentos HTML con la potencia de JavaScript.

1. ¿Qué es el DOM?

El DOM (Document Object Model) Es el elemento fundamental del JavaScript que se ejecuta en el navegador (lado del cliente). Funciona como la puerta de entrada principal a la página web, ofreciendo las propiedades (datos) y métodos (funciones) necesarios para inspeccionar, manipular y controlar todos los elementos que forman parte de la ventana actual.

"El DOM convierte un archivo estático en un conjunto de objetos vivos que reaccionan a las interacciones del usuario."

1. Métodos de Selección de Elementos

getElementById('id')

Selecciona un elemento único por su ID.

getElementsByTagName('tag')

Devuelve una colección viva (HTMLCollection) de etiquetas.

getElementsByName('nombre')

Devuelve una NodeList de elementos con el atributo name especificado.

2. Modificación de Contenido y Atributos

innerHTML

Obtiene o reemplaza todo el contenido HTML (incluidas etiquetas) dentro de un elemento.

setAttribute('atributo', 'valor')

Establece o actualiza el valor de un atributo HTML (ej. class, src, disabled).

3. Jerarquía y Navegación de Nodos

parentNode / childNodes

Accede al padre o a la lista completa de nodos hijos.

firstChild / lastChild

Obtiene el primer y último nodo hijo.

previousSibling / nextSibling

Accede al nodo hermano anterior o posterior.
